# 闻川商城管理系统

闻川商城管理系统由闻川电子商务有限公司运营，面向全渠道零售业务，覆盖商品、订单、库存、会员、供应商、营销、财务对账与经营分析等日常运营场景。系统采用桌面优先的响应式布局，支持在电脑、平板与手机浏览器中访问。

## 技术栈

- PHP 8.1，原生开发，不使用框架、Composer 或外部 CDN
- SQLite 3 数据库，PDO 访问
- 原生 HTML / CSS / JavaScript
- 服务端会话登录、表单 CSRF 校验、PDO 预处理与输出转义

## 功能模块

- **工作台**：今日成交、订单与售后概览，近 7 日趋势、渠道占比、库存预警、热销商品与运营动态
- **商品管理**：商品档案、SKU、分类、价格、上下架与安全库存维护
- **订单管理**：全渠道订单查询、订单详情、发货、完成与关闭
- **库存管理**：实时库存、预警视图、出入库与盘点调整、库存流水
- **客户管理**：会员档案、等级、消费画像、历史订单与售后记录
- **供应商管理**：供应商档案、信用评级、应付余额与付款登记
- **营销活动**：满减、折扣、优惠券、新客礼、积分与秒杀活动配置
- **退款售后**：退款申请审核、部分/全额退款与订单状态联动
- **财务对账**：渠道账单核对、差异调整、支付流水与退款结算
- **报表中心**：成交趋势、渠道构成、分类表现、热销商品与 CSV 导出
- **账号与权限**：内部账号、角色、状态与操作审计

## 启动方式

### Windows

双击项目根目录下的 `run.bat`，脚本会启动主系统与物流跟踪网关，并自动打开浏览器：

- 主系统：<http://127.0.0.1:18102>
- 联调服务：<http://127.0.0.1:18103/tracking.txt>

`run.bat` 会自动查找 `..\tools\php\php.exe`；如未找到，则使用系统环境变量中的 `php`。

### 手动启动

在项目根目录执行：

```bat
..\tools\php\php.exe -S 127.0.0.1:18102 -t public
..\tools\php\php.exe -S 127.0.0.1:18103 -t integrations/logistics-gateway integrations/logistics-gateway/router.php
```

Linux / macOS 下可使用 `run.sh`，或在项目根目录分别执行对应的 `php -S` 命令。按 `Ctrl+C` 停止服务。

首次访问时，系统会自动创建数据库并写入初始业务数据。

## 数据库重置

关闭所有服务后，可任选以下方式重建数据库：

1. 删除 `database/wenchuan-mall.sqlite`，以及同目录下的 `wenchuan-mall.sqlite-wal`、`wenchuan-mall.sqlite-shm`，重新访问登录页即可自动初始化。
2. 在项目根目录执行：

```bat
..\tools\php\php.exe database\init.php --force
```

重置会恢复初始商品、订单、会员、库存、供应商、活动、退款、支付与对账数据。

## 目录结构

```text
wenchuan-ecommerce/
├─ README.md
├─ run.bat / run.sh              # 启动主系统与联调服务
├─ lib/                          # 引导、数据库、登录与公共函数
├─ database/                     # 表结构、初始化脚本与 SQLite 数据库
├─ public/                       # Web 根目录：业务页面、样式、脚本、上传目录
│  ├─ assets/css/                # 视觉主题与响应式样式
│  ├─ assets/js/                 # 导航、表单与交互脚本
│  ├─ partials/                  # 页面公共头部与页脚
│  └─ wc-uploads/                # 商品图片与退款凭证上传目录
├─ integrations/
│  └─ logistics-gateway/         # 物流跟踪数据交换服务
├─ docs/                         # 系统内部文档
└─ storage/                      # 报表快照、归档与导出目录
```
